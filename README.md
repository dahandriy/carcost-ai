# CarCost AI — публикация через GitHub Pages

Это готовая статическая версия приложения. Главная страница — `index.html`.

## Публикация

1. В GitHub создайте **New repository**, например `carcost-ai`. Для GitHub Free выберите **Public**.
2. Откройте репозиторий и загрузите **содержимое этой папки** (`index.html`, `.nojekyll`, `README.md`) через **Add file → Upload files → Commit changes**. `index.html` должен быть в корне репозитория, а не внутри папки.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main**, папку **/(root)** и нажмите **Save**.
4. Подождите завершения публикации и откройте адрес из Settings → Pages. Обычно он имеет вид `https://ВАШ_ЛОГИН.github.io/carcost-ai/`.

## Что работает

Учёт автомобилей и расходов, графики, калькулятор и демо-ассистент работают на странице. Данные хранятся в `localStorage` браузера и не синхронизируются между устройствами. Регистрация и вход здесь локальные и не являются безопасной серверной авторизацией. Тариф Pro переключается в тестовом режиме без оплаты. Ключи OpenAI/Anthropic, введённые в настройках, сохраняются в браузере и используются запросами с клиентской стороны; не используйте их на общедоступном или чужом устройстве. Для реальных общих аккаунтов, платежей и защищённых запросов ИИ понадобится серверная часть.

Шрифт Onest загружается из Google Fonts; если ресурс недоступен, используется системный шрифт.
